MobileSAM 和 ACE2P 都是图像分割模型，但它们解决的问题不同。

MobileSAM：通用目标分割模型，擅长根据点、框等提示，精确提取任意物体的轮廓。

ACE2P：人体语义解析模型，擅长识别人体不同部位及服装类别，例如上衣、裤子、手臂、腿部等。

如果用于 AI 模特换装、裤子替换、局部重绘、蒙版生成，二者并不是简单的替代关系，而是具有互补性。

2. ACE2P

ACE2P（Augmented Context Embedding with Edge Perceiving）主要由以下能力组成：

上下文特征增强，提升人体部位语义识别。

边缘感知，改善人体及服装区域边界。

人体部位与服装类别的像素级预测。

ACE2P 采用的骨干网络、输入尺寸和实现版本会影响实际性能，因此不能直接拿 MobileSAM 的 12ms 与 ACE2P 做公平速度比较。

另外，ACE2P 与 SCHP 是不同的人体解析方案。SCHP 是可以一并评估的替代模型，而不是 ACE2P 的另一个名称。SCHP 的 LIP 模型支持包括 Pants、Left-arm、Right-arm、Left-leg 等在内的 20 类解析。

这里有一个重要的工程细节：人体解析的语义蒙版不能直接作为最终生成蒙版。 特别是手插兜场景，需要把可见手部作为保护区，同时根据目标裤子结构判断是否需要允许局部手部重绘。

如果 Seedream 所用 API 不支持直接上传蒙版，可以在服务端使用蒙版约束最终合成，但这只能保证未授权区域不被修改，不能保证生成模型内部严格按照蒙版理解和绘制。
