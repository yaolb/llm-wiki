# 紫东太初 ZDTaichu5.0‑9B：10B 内空间具身最强通用多模态模型

> 素材分析：微信公众号/头条账号「中科紫东太初」《重磅开源！紫东太初 ZDTaichu5.0‑9B》（2026-09-14），原文归档于 `raw/zdt-taichu-5-0-9b-toutiao.md`。实体页见 [[紫东太初]]。
>
> ⚠️ **可信度提示**：本文为**厂商官方发布**，基准成绩、"10B 内最强"、"对标 GPT‑6 Astra"等均为自述，**未提供第三方复现**。以下内容按"厂商声称"记录。

## 概述

紫东太初于 **2026-09-15 正式开源 ZDTaichu5.0‑9B**：参数量约 **9B**，支持单图、多图、长序列视频与**任意分辨率**视觉输入，聚焦真实物理场景下的**空间感知、跨视角变换、具身任务规划**。

厂商声称的三点主张：
1. **10B 参数内空间具身能力最强的通用多模态大模型**——九个国际权威空间理解基准拿下 **8 项组别第一**；
2. **通用能力不因空间能力增强而受损**（图文理解/OCR/视觉数学/代码 Agent 仍居第一梯队）——直击"提升空间具身能力往往牺牲通用多模态能力"的行业难点；
3. **不只开权重，还开放整套空间多模态数据生产管线**——直指"企业拿到权重却无法用自有工业/机器人数据迭代"的痛点。

## 1. 四层递进能力链条

```
空间感知 → 复杂三维空间推理 → 具身条件推理 → 物理交互决策
（看懂二维）                      （理解三维物理世界并规划决策）
```

**厂商给出的实测案例（自述，无第三方复现）**：

| 能力层 | 基准 | 声称表现 |
|--------|------|----------|
| 空间感知 / 视频目标定位 | "找从左到右第二个银色盒子" | **只有本模型输出正确坐标**，同级其他开源模型全部定位错误（厂商称这是机器人抓取的底层能力） |
| 复杂三维推演 | MindCube‑tiny | **78.27 分**，大幅领先同级竞品 |
| 跨视角推理 | ViewSpatial | 拉开差距；三视角实测中**只有本模型输出正确相对方位**，其余模型参照系错乱 |
| 具身交互 | ERQA、RoboSpatial | 同参数开源模型第一 |
| 交互可用性 | 杯柄侧空闲区域选择 | 输出点位落在**合理空闲区域**；对比模型点位全部落在被占用区域 |

横向对比对象：开源 Qwen3.5‑9B、STEP3‑VL‑10B、gemma4‑8B‑E4B；闭源 Gemini、Grok。

## 2. 自适应循环推理（Adaptive Loop Reasoning）

厂商称该机制与"业界猜测的 GPT‑6 Astra 所用 Loop Transformer 路线"高度前瞻一致，**在不扩张参数量的前提下提升有效推理深度**。

- **熵门控**判不确定性：确定性任务**直接输出、不耗额外算力**；空间变换、物体关系判别等高不确定任务，模型在**前向传播内部**循环迭代优化隐层表征，**不依赖外部思维链输出**
- **三重稳定化工程**：阻尼更新（damping update）+ 双重停止判据 + 轨迹读出与状态回滚 → 保障内部循环不发散
- **两层循环分工**：**内部循环**提升单步感知推理质量；**外部任务循环**接收环境反馈更新全局状态
- 设计意图：让**算力向高难度难题倾斜**，在不显著增加平均推理成本的前提下提升复杂任务正确率

## 3. 数据生产管线（本次开源最稀缺的部分）

覆盖 **预训练 → 监督微调 SFT → 高质量退火 → GRPO 可验证强化学习** 全环节，包含：

- 哈希‑URL 双重去重、画质过滤
- **三维能力标签体系**
- 思维链合成、一致性校验
- 能力域‑难度‑质量**三维自动标签系统**（退火+GRPO 阶段定向筛样）
- 多重自动奖励信号：答案正确性、**坐标命中**、格式合规 → 把空间点位输出与结构化规划转为可训练目标，适配长视频、长链条具身推理

**训练采用渐进式数据课程**：
1. **预训练**：整合开源图文、网页文档、视频、三维仿真场景多源数据 → 完成视觉、语言、时序、三维空间概念基础对齐
2. **SFT**：大规模任务轨迹样本，对具身样本**强制多维度一致性校验**，通过多轮对话与视频序列教会模型结合视觉证据完成任务拆解、工具调用、具身交互

## 4. 长程具身与落地场景

厂商称其能持续跟踪**物体身份、空间位置、任务进度**三者绑定，依据新观测更新状态，而非机械执行初始动作列表：

- **端侧/设备控制**：无需人工分步引导，融合实时图像 + 用户目标 + 设备执行反馈，自主研判并输出控制指令，全程闭环
- **科研自动化**
  - 干实验：接收自然语言科学问题 → 自主调用 Python/SciPy → 同时求解析解与数值解并交叉比对 → 输出相空间图、位移‑速度时序曲线等可视化产物
  - 湿实验：复杂实验环境中跟踪物体状态/空间关系/任务进度，动态更新策略
- **智能制造**：备料配送、机台上料；应对密集货架、零件外观相似、遮挡等现实问题；从工单文本 → 高层语义理解 → 完整规划（货架取件 → 避障搬运 → 放置到位）

## 5. 评价与本库定位

**增量价值**：
- 「**空间能力↑但不牺牲通用能力**」是具身模型公认的老大难，若属实，价值高于单纯跑分；
- **开放数据管线而非只开权重**——具身/工业场景的数据工艺长期是少数团队的门槛，这一条产业价值大于权重本身；
