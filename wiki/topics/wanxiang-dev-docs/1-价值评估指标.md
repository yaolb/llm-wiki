### 一、指标说明


**（1）概览**


| 场景总结 | 业务评估指标 | 平台评估指标 |
| --- | --- | --- |
| 拉新（交叉场景） | CTR、CVR | 用户复用度 |
| 促活 | 用户粘性度 |  |
| 促转 | - |  |


区别在于关注的深度

**（2）详情**


| 模式 | 场景 | 指标名称 | 指标定义 | 计算口径 | 备注 |
| --- | --- | --- | --- | --- | --- |
| GMV | 拉新（交叉场景）+促活 | CTR | 合作项目中，应用万象触达用户中，点击用户的比例（保障量不变的情况下，对比应用前后值） | CTR=点击uv/触达uv |  |
| 促转 | 订单转化率（CVR） | 合作项目中，应用万象点击用户中，下单用户的比例（保障量不变的情况下，对比应用前后值） | 订单转化率=下单uv/点击uv |  |  |
| Listing | 拉新（交叉场景）+促活 | CTR | 合作项目中，应用万象触达用户中，点击用户的比例（保障量不变的情况下，对比应用前后值） | CTR=点击uv/触达uv |  |
| 促转 | 有效连接转化率（CVR） | 合作项目中，应用万象点击用户中，产生有效连接用户的比例（保障量不变的情况下，对比应用前后值） | 有效连接转化率=有效连接uv/点击uv | 有效连接定义待确认 |  |
| 平台 | 拉新（交叉场景） | 用户复用度 | 站在平台角度，单业务活跃用户需求被万象正确识别，并引流至多业务线比例 | 用户复用度=（有效访问1个业务且来源于非四大业务的dou X 1 + 有效访问2个业务的dou X 2 + 有效访问3个业务的dou X 3 + 有效访问4个业务的douX 4）/四大业务dou之和 | 有效访问：访问深度>x（参考经营日报vppv） |
| 用户粘性度（活跃度） | 站在平台角度，单业务活跃用户需求被万象正确识别，并引流至多业务线，并持续保持多业务线用户活跃度程度 | 用户粘性度=∑四大业务DAU/∑四大业务MAU（滚动30天） | 统计逻辑有去重与不去重两套（需数据验证） |  |  |
| 促活 | 用户粘性度（活跃度） | 站在平台角度，非活跃用户需求被万象正确识别并成功唤醒，提升平台整体保持用户活跃度程度 | 用户粘性度=平台DAU/平台MAU（滚动30天） | 统计逻辑有去重与不去重两套（需数据验证） |  |
