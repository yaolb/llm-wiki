# 工作记忆的分裂吸引子：一半管记什么，一半管何时记

> 来源：「Brain博览记2026」（2026-10-18）对 Nature 论文的解读

## 论文信息

- **标题**：A split attractor design for rapidly writing a navigational goal
- **期刊**：Nature，**2026-10-07** 在线发表；影响因子 56.1（2025 JCR Q1）
- **方法**：在体双光子钙成像 + 离体全细胞电生理 + 基于连接组的计算建模
- **被试**：雌性果蝇（1–14 日龄，多种转基因品系）

## 一句话

**它找到了工作记忆「既稳定又随时可改写」的电路解法：把网络拆成两半——一半存内容，一半管写入时机。**

稳定与灵活在模型里天然打架：

- 负责「记住」的网络必须**足够稳定**，否则记忆几毫秒就散了
- 可它又必须**随时开关**：新信息来了要写入，任务结束了要清空

> 经典吸引子网络一旦激活就很难关掉；模型作者通常直接加一个「门」，但**生物学里的门长什么样、装在哪，没人说得清**。

## 研究背景：为什么是果蝇

复馈（recurrent）网络被广泛认为是工作记忆基础：神经元彼此激励把活动「兜住」，持续发放远超单个神经元的膜时间常数——**持续性来自网络互动，不来自单细胞**。

果蝇是理想对象：

- **连接组**把每个突触都数清楚了
- **遗传工具**能精确操控同一批神经元
- 中央复合体的**扇形体（FB）**里，h∆K 与 PFG 两类局部神经元在柱状结构中结成**环状复馈**
- PFG 接收**罗盘系统的航向输入**，两者还共同接收全局输入——架构像极了经典工作记忆模型

## 三线并进的实验

- **在体成像**：果蝇踩气垫球行走，球转动闭环控制风向；双光子记录 FB 神经元。气味刺激（0.5% 苹果醋），分析休息/转弯/直线奔跑三种状态
- **离体电生理**：全细胞记录 h∆K，光遗传逐一激活突触伙伴，配合药理阻断与破伤风毒素（TNTe）
- **计算建模**：按 hemibrain 连接组真实结构建 **30 个 h∆K + 18 个 PFG + 1 个抑制性切向神经元**的速率模型

## 五个核心发现

### 一、持续性来自网络，不来自单细胞

气味出现时，h∆K 与 PFG 都在 FB 上产生局部化的活动「**凸包（bump）**」，并在保持目标航向期间持续。

**关键对应**：bump 消失的时刻，正是果蝇偏离目标方向的时刻。

电生理追责：h∆K 对电流注入只有**即时反应**、没有内在持续性；但阻断它自身的突触输出（TNTe）后，**持续兴奋消失**。

### 二、慢兴奋 + 快抑制：稳定性的配方

- **兴奋是慢的**：胆碱能输入（FB6A/D）、PFG、5-羟色胺能 ExR3 → h∆K 缓慢而持续的兴奋；可被烟碱或 5-HT 拮抗剂削弱
- **抑制是快的**：FB5V 与 FB6M 一激活就立刻压制，且能被 GABAA 拮抗剂 picrotoxin **翻转成兴奋**

**建模含义**：如果复馈兴奋也快，只有极窄的强度组合能产生缓慢衰减的持续活动，稍偏就跳到「瞬间衰减」或「永不衰减」。

> 换成慢兴奋后，**稳定持续活动的参数域大幅扩张**；小幅调节强度就能平滑调节「记多久」；加入试次间噪声，模型再现了实验观察到的持续时长分布。

两个节点的极简模型也能复现 → **这是复馈回路的通用设计原则，不挑网络构型**。

### 三、转弯时，两半网络说散就散

- **直线奔跑**：h∆K 与 PFG 都有高幅 bump
- **转弯/休息**：PFG 仍保持**低幅** bump，位置随转弯在柱间平移（像罗盘跟踪航向）；**h∆K 几乎沉默**，转弯结束后才在新位置重新出现

「风移」实验量化了切换：突然把风向转 90°——

- PFG 幅度**低**时：位置跟着航向走（旋转增益接近 **1**）
- PFG 幅度**高**时：位置纹丝不动（增益接近 **0**）

> 同一群神经元在「**跟随模式**」与「**锁定模式**」之间切换；气味出现会把它们推向锁定。

### 四、模型：抑制一半，就是开关

连接组给出最后一块拼图：**只有 PFG 直接接收罗盘输入**，且该前馈输入比 h∆K–PFG 复馈弱得多（模型里复馈:罗盘 = **3.5:1**）。

仿真结果：

- **强抑制 h∆K** → PFG 低幅跟随罗盘
- **解除抑制（去抑制）** → 复馈立刻把当前罗盘位置「锁」成高幅稳定 bump，像数字电路的**锁存器**
- **连续两次去抑制** → 先后写入两个不同航向

> **记忆的「内容」由 PFG 携带，「写入时机」由对 h∆K 的抑制控制**——把输入与开关分到两半，就是稳定与灵活兼得的设计。

### 五、在体验证：找到刹车踏板

对 FB5V（每侧 9 个、专门抑制 h∆K）在体成像：

- **紧张性放电**，气味时被强烈抑制，且持续到气味后的逆风行走期
- 活动与**角速度正相关**、与**逆风速度负相关**
- **大转弯（>130°）时飙升**，偏离目标方向时也升高

> 每一次该「松刹车」的时刻（气味、目标行走）它都在松；每一次该「踩刹车」的时刻（转弯、偏离）它都在踩——与去抑制模型预测完全吻合。

FB6M 角色不同：同时支配两群神经元，更像**许可性的共同调节器**，而不是解耦开关。

## 设计原则总结

**分裂吸引子 + 去抑制门控**

- **慢兴奋** → 吸引子稳定且可调
- **快抑制** → 配合行为状态做快速开关
- **网络拆两半** → 一半携带内容，一半受门控控制写入时机

作者认为这可能是**复馈回路兼顾稳定与灵活的通用解**：从果蝇导航记忆到哺乳动物前额叶工作记忆，可能用同一套思路。

## 作者自认的局限

- 部分持续性可能来自**上游**（FB5V 的抑制在气味后仍持续，其上游蘑菇体输出神经元可能参与）
- 严格检验仍需**额外因果实验**（如直接激活/沉默 FB5V，预测两群神经元的可检验变化）
- **光遗传整类激活**可能带来非生理去极化；单细胞反应存在异质性
